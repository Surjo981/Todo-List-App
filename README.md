<h1 align="center">🌐 Todo List App</h1>

<p align="center">
  <b>A powerful, responsive, and user-friendly task management app built with HTML, CSS, and JavaScript.</b>
</p>

---

## ✨ Features
- 🗂️ Add multiple todo lists  
- ✏️ Add, edit, and delete tasks  
- ✅ Mark tasks as complete  
- 📤 Import and export todo lists  
- 📱 Edit and delete tasks using swipe gestures (mobile & tablet)  
- 💻 Fully responsive design across all devices  

## 🧩 Built With
- **HTML5** – Structure  
- **CSS3** – Styling & Layout  
- **JavaScript (ES6)** – Logic & Interactivity
